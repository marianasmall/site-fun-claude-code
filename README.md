# Mariana's Claude Code Tips (site)

Short, tried-and-tested Claude Code tips you can copy and paste, each with a date so you know it still works.

**Who this is for:** people who use Claude for real work and want more out of it, without needing to code.

customizations (spinner verbs, mascots, sounds, themes, and more).

- **Read the tips:** https://fun-claude-code.netlify.app
- **Install the files:** https://github.com/marianasmall/claude-code-starter-kit

## Repo layout
| Path | What |
|------|------|
| `site/index.html` | The whole site — one self-contained file, deployed via Netlify |
| `md/` | Per-tip markdown/PDF source versions |
| `TIPS-REGISTRY.md` | Freshness ledger: every tip, its dependency, and when it was last verified |
| `AGENTS.md` | Contributor/AI briefing — including the mandatory freshness rule for updates |

Every tip on the page carries a date pill (**Added / Updated / verified**) so readers always know
what's current. The registry + the rule in AGENTS.md are what keep those pills honest.
