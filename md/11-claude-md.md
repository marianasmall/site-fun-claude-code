# The Memory File (P4)

<p class="tagline">Teach Claude how you work — once. Added Aug 7, 2026.</p>

CLAUDE.md holds your standing instructions: who you are, what to always do, what to never do. Lives at `~/.claude/CLAUDE.md` (global) or in a project folder (local). Every session starts already knowing you.

**Paste:**

> Create a CLAUDE.md for me: interview me about how I like to work — my role, how technical I am, what you should always do, and what you should never do — then write the file and tell me how to change it later.

**The compounding trick:** corrected Claude the same way twice? Say "add that to my CLAUDE.md."

What belongs: who you are · standing rules · preferences · recurring corrections. The starter kit ships a filled-in `CLAUDE.md.template`. Docs: code.claude.com/docs/en/memory
