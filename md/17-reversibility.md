# Reversibility (P10)

<p class="tagline">Never let Claude do anything you can't undo. Added Aug 7, 2026.</p>

The rule that makes it safe to hand Claude real work: nothing destructive, ever. You keep the only delete key.

**Four standing rules, one paste:**

> Add these standing rules to my CLAUDE.md: 1) Never delete files — move them to a "Review for Deletion" folder and tell me. 2) Never send emails or messages — create drafts for my review. 3) Before overwriting any file, save a backup copy first. 4) If an action can't be made reversible, stop and ask me before doing it.

**Why it changes everything:** once nothing can go permanently wrong, you stop supervising every step — and that's when Claude becomes genuinely useful. Reversible beats confirmed: a review folder you empty weekly beats a hundred "are you sure?" prompts.

Pairs with P6 (plan mode): see the plan before it runs, and even if something slips through, it's reversible anyway.

Kit users get part of this in hardware: `backup-before-edit` snapshots every file before edits; `safety-net` hard-blocks destructive commands.
